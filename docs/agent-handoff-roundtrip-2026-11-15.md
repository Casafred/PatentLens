# Agent 结构化结果回流：第一轮

本轮接通「权利要求生图」与「同族权利要求比对」，使用同一任务信封、结果信封和交接面板。外部 Agent 负责分析，软件负责原文校验、本地渲染、版本与导出。本功能不调用模型 API。

## 使用

### 权利要求生图

1. 从专利打开成图工作台，或在工作台输入权项；多条输入时选中当前需要分析的一条。
2. 点击「交给 Agent 生图 / 导入结果」，新建任务，复制指令或下载任务材料。
3. 把指令或任务材料发送到外部 Agent，取得完整 JSON 结果文件或完整回答。
4. 将结果文件直接拖到成图工作台，或在交接面板选择文件、粘贴回答。
5. 导入后生成可编辑图。修正后的结果追加为新版本；同一份结果不会重复生成。

图继续支持现有手动编辑和导出。原始公开号、非连续权项编号及来源快照保留。原权项已修改、重新分析或画布删除时，导入会说明原因，要求使用匹配的原任务。

### 同族比对

1. 在智能比对中准备权项，勾选参与项并设置锚点。
2. 点击「交给 Agent / 导入结果」，新建并复制任务。
3. 返回文件可直接拖到比对区域，也可在面板选择文件或粘贴回答。
4. 返回内容进入现有统一特征树、逐权项采用矩阵、证据详情、比对历史与 HTML 导出。

输入包含实际引用祖先的上下文。树的分组关系不代表法律上的 AND/OR；组合表达、范围判断、参数与引用路径由现有 familyScope 结构保留。证据不足的映射降级为待核对。缺少整列或重复权项 ID 的返回需要修正后再导入。

## 任务与结果

任务记录包含 `kind=patentlens-agent-task`、`schemaVersion=1`、`taskId`、`taskType`、`sourceHash`、完整 `input`、提示词、目标位置和状态。

结果必须为一个完整信封：

```json
{
  "kind": "patentlens-agent-result",
  "schemaVersion": 1,
  "taskId": "原任务编号",
  "taskType": "claim-graph 或 family-comparison",
  "sourceHash": "直接复制原任务值",
  "payload": {}
}
```

`payload` 必须填写实际结果，不能保留空对象：

- `claim-graph`：沿用 Patent2Pic 的 ExtractResult，包括 claimType、nodes、edges、groups、sentencePairs 等。
- `family-comparison`：包含 familyScope，可附带 report 和 similarityScores。

SHA-256 由软件根据输入快照计算，Agent 不需要计算。导入同时核对本地任务快照、信封值与仍存在的当前原文。hash 用于版本关联，不验证专业判断的正确性。

## 校验与保存

- 不修补截断 JSON 后成图。要求完整结果信封；支持完整 JSON 和 Markdown JSON 围栏。
- 生图核对节点/边 ID、连接目标、分组/分步引用、节点与关系原文、完整原译文顺序。
- 同族复用 FamilyScope 的来源权限和原文证据检查，无法验证的积极映射显示待核对。
- 导入中的内容按文本或已有转义视图显示，不执行 Agent 返回的 HTML。
- 保存最新原始回答与错误，可下载原始回答、复制修正请求。格式错误时按当前选中的任务保留回答。
- 最多保留 20 个任务，结果文件最多 4 MB；不截断任务原文。空间不足会报错，要求下载和整理旧记录。
- 第二轮起，所有类型交接记录统一写入 Electron 用户数据目录的 `agent-handoff-tasks.json`，支持换端口恢复，原生图与同族任务自动迁入。详见第二轮文档。
- Electron 复制走主进程 IPC，只接受本地工作台主框架和限定大小的文本。

## 验证

- `npm test`：协议、版本匹配、重复回流、失败恢复、图结构和原文校验、同族证据降级、剪贴板 IPC 权限。
- `npm run build:patent2pic`：TypeScript 检查及生产构建。
- `npm run test:agent-handoff-smoke`：实际 Electron、真实编辑器与本地成图，覆盖复制、直接文件拖入、新版本、错误证据、换端口恢复、同族树/历史/导出，模型调用为 0。
- 原有 Electron、Patent2Pic 与权项比对冒烟测试用于回归。

自动化使用开发样例，不代表真实同族分析准确率或所有外部平台的格式遵循率。专利原文仍需先由软件加载或用户提供。

第一轮验证结果：241 项 Node 测试全部通过；生产构建、渲染器冻结检查、重构校验、Electron 主界面、Patent2Pic、权项比对及新增交接冒烟测试全部通过。新增交接冒烟期间模型请求数为 0。
