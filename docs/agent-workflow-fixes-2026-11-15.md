# Agent 交接修复与界面调整

基于包含 Agent 回流功能的 `978ea4b`（与远端 main 的 `cf50ac7` 文件树一致），修复与新界面位于 `src/scripts/app/features/`，由 Electron 的 `src/web.html` 加载。本次没有迁出或修改 `web-app.js`；`src/index.html` 没有加载这套交接模块，无需镜像新增界面。未修改冻结的 Tauri 实现。

## 操作入口

- 智能助手、生图工作台、Agent 任务、审查文档阅读器合并为可拖动的竖排工具栏。鼠标靠近时向窗口内侧沿圆弧展开图标与名称，离开延迟收起；支持点击、键盘展开、Escape 收起与方向键移动。位置保存本机，窗口缩放后限位，保留设置中的助手/生图入口开关。
- 旧审查报告的继续问入口收进智能助手面板，消除原来与回顶部重叠的独立紫色浮球。
- 原文详情页“交给 Agent”放在原有链接与操作按钮一行，弹窗入口位于弹窗操作栏、关闭按钮之前，避免独立工具条被吸顶页头覆盖。
- 时间轴、审查文档列表和看板只保留一个“交给 Agent”入口。点开后选择“分析审查意见与答复”“复制材料 / 导出 PDF”或“继续已有任务 / 导入结果”。原有分析、导出按钮继续可用。

## 任务流程

1. **准备材料**：填写目标和原文，或在业务工作台沿用当前材料创建任务。
2. **交给 Agent**：复制包含材料的任务指令，粘贴到外部 Agent。也可下载任务文件；仅长材料显示分包选择。
3. **带回结果**：拖入结果文件或粘贴完整回答。查看报告与证据，再确认采用。

已有结果时优先展示报告与证据；追加回答的输入区折叠。结构化修订、原分析备份、任务迁移和删除放在折叠区。导入失败时提供修正请求入口。步骤支持键盘切换，面板保留焦点约束和 Escape 关闭。

## 数据修复

- 旧原文入口通过 `getCurrentData()` 优先读取遗留弹窗或审查概要，造成详情缓存明明有全文却显示不可用。现在案卷与原文分开读取：详情读取当前原文，弹窗读取当前弹窗；按同一文献号补齐内存及磁盘缓存，拒绝其他专利的数据，也不修改缓存。
- PDF 与附图载荷不再随每次渲染重建。准备成功后仍可拖出；失败可重试，IPC 异常会显示错误。关闭或切换交接面板后，旧异步任务不会写入新面板。
- 审查文档勾选后同步更新 OCR 材料和 PDF 列表；取消后重新勾选，已准备文件仍保留。
- 未进入文档选择模式时，空选择集按已加载文档创建审查任务。
- 材料预览与复制使用相同指令拼装方式，包括通用要求。

## 单篇审查文档

- “问一问 · Agent”、OCR 与全文/选区翻译入口由独立模块接管，阻止旧内置 OCR/AI 点击与 Enter 发送事件。阅读器隐藏模型配置，采用「准备材料 → 交给 Agent → 带回结果」流程。
- OCR 无需先有提取内容；任务包含本篇 PDF 附件描述，可准备、拖出或打开文件位置。OCR 返回逐页文字，保留页码与未完成页提示，并更新提取面板和原文视图。
- 对照翻译基于现有全文或所选块，严格核对来源编号、逐字原文和完整覆盖；缺少文本时提示先交给 Agent OCR。译文按原文/译文逐段展示。
- 问答携带当前篇全文和用户问题；无提取内容时可附 PDF。引文必须能在输入来源中核实。
- 回答先保存为版本，用户核对后采用。采用前检查案卷、文档 ID、PDF 来源和提取内容版本，异步保存期间再次检查，备份原内容。采用记录随台账持久保存；切换文档与重新打开后恢复对应的翻译和回答。
