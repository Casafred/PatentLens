# Agent 交接第二轮

## 四项业务入口

| 功能 | 入口与材料 | 回流与采用 |
| --- | --- | --- |
| 权项支撑定位 | 权利要求支撑面板“交给 Agent / 导入”；沿用面板所选权项，提供完整说明书段落 | 校验每个特征、段落、逐字引文，保存审核版本；采用后进入原支撑证据面板，段落可点击定位 |
| 审查与答复分析 | 时间轴、案卷及看板“Agent 审查分析 / 导入”；沿用所选文档，包含完整 OCR 与缺失文档清单 | 保存报告版本；采用前备份原分析，采用后接入当前分析、章节导航及原有缓存/导出流程，证据可查看原文快照 |
| 分享内容加工 | 分享工作台“Agent 加工 / 导入”；可选专利、技术解读/技术要素/实施例/多专利比较/已有自定义字段 | 遵守项目/字段原文范围及提示词；采用后追加可编辑加工草稿，保持 pending，沿用分享审核流程；已有人工和已确认字段不覆盖 |
| 自然语言修改图 | 画布“AI 重构”→输入要求→“交给 Agent 修改 / 导入”，无 API Key 也可进入 | 交接当前画布含手工编辑，或选中的原始抽取基准；返回完整图后新增可编辑版本，保留来源版本和修改摘要 |

本轮未提取或新增 `web-app.js` 代码，桌面集成只使用 Electron；`src-tauri/` 未修改。

## 公共能力

- 主界面右下角“Agent 任务”统一台账，包含生图、重构、同族、支撑、审查、分享和通用报告。
- 台账可填写目标和原文，创建通用报告任务；报告格式为 `report` 字符串和 `evidence` 数组。
- 保存完整任务、最新原始回答/错误、每次成功返回的 payload、结果哈希、时间及采用记录。可选择旧版本、编辑结构化结果并保存新修订。格式错误时仍可下载回答和复制修正请求。
- 采用前的审查分析保留独立备份，可在任务面板查看或下载。分享草稿使用任务/结果哈希去重，提示词仍保留实际加工要求。
- 主进程按顺序原子写入用户数据目录，保留 `.bak`；台账不再随 HTTP 端口改变。旧 localStorage 同族任务与生图工作区任务在成功迁移后清理旧键。
- 导出全部任务包、导入包、合并同编号任务的新修订；校验整包后一次写入，冲突/损坏不部分导入。来源材料及修订内容均核对哈希。
- 图任务可在原文和来源一致时手动“绑定当前画布”，然后继续导入；不会按近似文字静默绑定其他权项。
- 文档、权项、段落/文本偏移使用确定性编号。证据引文必须存在于指向的原文。点击证据展示冻结快照；当前文档的 OCR block 定位索引存在，或当前专利段落一致时，还可跳到工作台原文。

## 长材料

原文不截断。长文本按不超过 12,000 字符的片段提供，片段 ID 带原文偏移；分包目标约 24,000 字符的来源材料。选“完整材料”一次返回，或逐个选 `part-N` 复制/下载并返回。

分包必须携带信封 `partId`。未收齐只保存，不写入业务页面。收齐后：报告按包汇集为章节；分享按专利汇集；支撑按权项和完全一致的原文特征合并引文。返回重复包可替换该包并重新合并。任何最终合并结果仍须业务校验和人工采用。

合并不是新一轮模型推理：跨包审查结论、同义但切分边界不同的特征、重复或冲突内容需人工复核，可编辑结果或交给 Agent 再修订。生图与同族结构回流沿用完整返回，不提供结构图分包合并。

每个台账最多 20 个任务、总计 32 MiB 字符预算；单任务序列化材料最多 12 MiB 字符，单次结果最多 4 MiB 字符（文件入口按字节限制）。复制还受 IPC 的 8 MiB UTF-8 字节限制，大任务可下载文件。超限明确报错，不自动删除历史或截断原文。

## 边界

- 图修改允许保留已有手工对象。新增/修改对象无法在权项验证时，必须返回 `proposals: [{id, reason}]`，图中加“【示意】”，原文位置改为用户修改要求，不伪装成权项引文。
- 保留原动画帧时删除已经不存在的对象引用。重构保留基准快照和版本链；后来在原图上的修改不影响交接快照，新结果始终追加版本。
- 支撑证据校验不作支持性或有效性法律判断。无有效证据的特征显示待核查。
- 报告界面把内容作为文本/转义 Markdown 处理；进入旧审查缓存渲染链路前禁用输入 HTML 与链接语法。
- 迁移包迁移任务、材料和结果，不自动迁移分享项目、案卷 PDF、完整生图项目或模型配置。业务采用仍校验当前原文与目标；应先迁移相应项目/载入相应材料。分享项目现有 IndexedDB 与比对历史本身的存储边界未改变。
- 审查报告的完整结果与证据始终保存在磁盘台账；业务页沿用现有案卷缓存。分享页沿用 IndexedDB 的审核、编辑和分享机制，草稿中保留原有字段允许的前 20 条引文，完整证据见任务版本。

## 验证

Node 测试覆盖来源全文分片、错引、原文变更、分包完整性、结果修订和采用记录、手工分析保留、草稿去重、任务迁移合并、IPC 写入序列与备份恢复。Electron 冒烟覆盖四项实际入口/回流/采用及原生图、同族比对、端口变化后的台账恢复；测试不调用外部模型。

本轮验证：249 项 Node 测试通过；Patent2Pic 生产构建、渲染器冻结检查、重构验证、Electron 主界面/权项比对/Patent2Pic/Agent 交接四套冒烟通过。Agent 交接冒烟中的模型请求数为 0。

外部 Agent 的专业分析准确率和不同平台的格式遵循率尚需实际专利材料验证。
