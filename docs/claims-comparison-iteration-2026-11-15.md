# 权利要求对比迭代与后续方向

基线：GitHub `Casafred/PatentLens`，`main` 提交 `d9d48e1`。开发日期：2026-11-15。应用入口为 Electron `src/web.html`，未修改冻结的 `web-app.js` 或 Tauri。

## 审视结论

现有本地算法已能对齐权项、定位词句变化、绘制依赖演变树，但原先默认展示展开的长列表，编号调整和实质变化混排，读者需要逐项展开原文才能找到变化。引用对象变化会被当作纯重编号；父项内容变化对从权继承限定的影响没有单列。

原有同族 AI 比对输出 Markdown 报告和相似度，缺少可复用的特征字典、逐权项映射和原文校验。其系统提示词把半封闭与开放式表述混为同义，并要求强制宽窄排序，会影响范围判断。

## 已实现

### 公开—授权 / OCR 修改版本

- 默认进入演变树，保留变化清单切换。
- 增加内容 / 结构变化、编号 / 引用调整、新增、保持一致四类可点击概览。
- 树节点展示文本预览，支持键盘操作、文本或编号查找、上一 / 下一变化。
- 详情先给变化片段，再给完整双栏原文；编号与引用重编号默认折叠。
- 低文本匹配与可能限定并入显示候选关系提示，不宣称已作法律判断。
- 区分单纯重编号与引用对象变化，保留多项引用 AND / OR 改变。
- 父项内容变化可沿引用路径传递到从权，显示“引用路径影响”；从权自身文本与继承影响分别呈现。
- 树标题支持基准版本和 OCR 修改版本，避免一律称为公开 / 授权。

### 同族 AI 特征树

使用现有 AI 服务商与同一次分析请求，在报告后要求输出 `familyScope` 结构。AI 负责语义归一，前端负责取证校验、层级处理与绘制。

- 左侧为全体已选权项的统一要素并集，包含非锚点成员的独有要素；支持父子分组。
- 每列是一条已选权项，保留同一成员的不同独权方案，不把它们拼成 AND。
- 单元格区分采用、译法不同、更具体、更概括、限定不同、未见记载、待核对。
- 点击显示原文片段、AI 中文译文、来源权项、继承标记、映射置信度与完整原文。
- 支持层级折叠、展开全部、差异 / 待核对筛选及术语搜索。
- 各权项组合卡片保留模型给出的 AND / OR、参数范围和引用路径，并显示相对锚点的范围判断理由。
- 通过已加载权项补齐实际引用的祖先上下文；不借用无关兄弟权项或其他成员取证。
- 引文必须在本权项或实际祖先来源中出现；证据缺失、引文无法匹配、映射置信度缺失或低于 0.65 的正向映射显示待核对。该阈值是阅读提示，不是法律准确率。
- 缺失或重复映射不自动补成“未采用”；“未见记载”不等于排除特征。
- 无效层级或循环安全恢复；缺失、截断或无结构化 AI 输出时保留原报告并说明树不可用。
- 历史保存证据源并可重建树；旧记录可继续阅读报告，重新分析后才可能生成树。
- 导出的独立 HTML 带特征树矩阵、逐格原文证据与组合解读，适配打印。
- 覆盖范围始终限定为已选权项，未加载成员和未选权项不计作已分析的整个族。

树的父子关系仅表示要素阅读分组，不能替代权利要求的逻辑表达。范围判断仍为 AI 解读，未以特征数量或相似度推断宽窄。原文存在校验也不能证明语义映射必然正确。

- 界面验证使用明确标注的开发样例，不代表真实族分析结论；未读取用户密钥或执行付费 AI / 专利数据请求。真实跨语言族的准确率和大规模性能尚需实测。

## 下一轮优先方向

1. **人工修订与重算**：支持合并 / 拆分归一要素、修改映射状态、确认译法与证据；保存修订与原 AI 输出的对应记录。先建立可纠错能力，再将树用于正式业务结论。
2. **真实族评测集**：按中文 / 英文 / 日文和多独权、多项从属、分案、部分连续申请等类型建立带专家标注的案例，分别统计术语对齐、遗漏特征、范围变化与继承关系的准确率。
3. **分阶段结构化分析**：按成员抽取要素，统一词典后逐权项映射，最后复核关键差异。大族按批处理、保留失败成员、支持增量补齐，避免一次输出过长而截断。
4. **逻辑与范围可视化**：把 AND / OR、可选分支、数值区间与排除项升级为经证据核对的结构表达；再建立方案组合分支图或范围包含图。不能从普通要素树直接推导法律包含关系。
5. **成员与版本双轴**：支持按国家 / 地区分组列、锁定或隐藏成员、公开 / 授权 / 修订版本切换、成员独有要素聚焦。大型矩阵采用虚拟滚动。

建议把“人工纠错 + 真实评测”作为下一轮首要目标；两者决定归一特征树能否从阅读辅助走向稳定的业务工具。
