# Patent2Pic embedded editor

Source: https://github.com/Casafred/patent2pic

Snapshot: `8b213ad311352429edec0f9d3b93921c193e3c7a` (frontend `src/`).

This package preserves the Vue / Pinia / X6 / ELK editor, graph semantics,
layout, style tools, animation playback, translation, prompts, task queue,
redraw versions, recycle bin and project/export formats. It is built as static
assets hosted inside PatentLens Electron; it does not ship another desktop
runtime, server, or Tauri bridge.

Integration changes:

- `services/host`: same-origin host bridge and serialized durable storage.
- AI profiles and credentials are owned by PatentLens; the editor receives
  profile metadata and streams, never a copy of the configured API keys.
- Host imports preserve publication number, original claim number, original
  text, source and language. Reopening the same selection resumes the project.
- Browser downloads replace native desktop export dialogs; `.p2p` remains
  compatible with the upstream 1.2.0 project format and older import paths.
- Fixes include structured claim import, nonconsecutive numbering, editing
  keyboard shortcuts, task target isolation, X6 label stage compatibility and
  safe serialization of patent text inside exported HTML.

Build from repository root: `npm run build:patent2pic`.
Generated assets: `src/features/patent2pic/` (ignored; regenerated by `beforePack`).

Upstream updates should be reviewed as frontend source changes and keep the
host interfaces in `src/types/host.ts` stable. Do not replace host integration
with upstream native runtime code or its separate API configuration storage.
